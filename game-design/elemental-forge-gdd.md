# 원소 카드 게임 기획서

**가제**: Elemental Forge (원소 합성사)  
**버전**: 0.1 (초안)

---

## 1. 게임 개요

원소 주기율표의 원소 카드를 조합하여 실존하는 분자와 화합물을 구성하고,  
매 턴 상승하는 득점 커트라인을 넘어 생존하는 **덱빌딩 카드 게임**.

- **장르**: 덱빌딩 / 생존
- **플레이어**: 1인 (솔로)
- **핵심 키워드**: 원소 조합, 화합물 합성, 반응 연계, 덱 성장

---

## 2. 핵심 메커니즘 요약

1. 덱에서 카드를 드로우하여 **실존하는** 분자/화합물 구성
2. 구성한 분자들 간의 화학 반응으로 추가 점수 획득
3. 매 턴 증가하는 커트라인 통과 시 연구 포인트로 새 원소 카드 획득
4. 더 강력한 화합물을 만들 수 있는 덱으로 성장

> 실존하지 않는 화합물, 원자가 규칙 미충족 조합은 점수 없음.

## 4. 득점 방식

### 기본 점수

분자를 구성하는 원소들의 **원자번호 합산**

```
H₂O  : 1 + 1 + 8        = 10점
CO₂  : 6 + 8 + 8        = 22점
NH₃  : 7 + 1 + 1 + 1   = 10점
NaCl : 11 + 17          = 28점
```

## 6. 덱 구성 방식 (카드 추가)

### 연구 포인트 시스템

매 턴 커트라인 통과 시:
```
연구 포인트 = 획득 점수 - 커트라인
```

### 연구 상점

턴 종료 후 **등급별 원소 카드 3장 랜덤 공개**, 연구 포인트 소비하여 구매.

| 등급 | 카드 비용 | 상점 해금 조건 |
|------|-----------|---------------|
| Grade 2 | 15 ~ 25pt | 턴 1부터 |
| Grade 3 | 35 ~ 55pt | 5턴 이후 |
| Grade 4 | 70 ~ 100pt | 10턴 이후 |
| Grade 5 | 150pt 이상 | 15턴 이후 |

### 주기율표 인접 해금 (선택 규칙)

보다 테마틱한 방식으로, 현재 덱에 있는 원소와 **주기율표상 인접한 원소만** 상점에 등장.

- H, C, O 보유 → N, F, S, P 등이 우선 등장
- 덱이 다양해질수록 상점 선택지도 넓어짐

## 7. 분자/화합물 상호작용 시스템 ⭐

> **게임의 핵심.** 단순 분자 합산이 아닌, 분자들 간 화학적 관계가 점수를 결정한다.

---

### 7-1. 화학 반응 연계 (Reaction Chain)

같은 턴에 형성된 두 분자가 실제 화학 반응을 일으킬 수 있으면,  
반응 생성물도 **자동 합성**되어 추가 점수 획득.

**규칙**
- 반응 생성물은 카드를 추가 소모하지 않음
- 반응 생성물의 점수는 **기본 점수 × 0.5** (카드 없이 생성이므로)
- 반응이 연쇄될 경우 각 단계마다 추가 점수

**예시**

| 반응물 A | 반응물 B | 생성물 | 설명 |
|----------|----------|--------|------|
| CO₂ | H₂O | H₂CO₃ | 탄산 생성 |
| NH₃ | HCl | NH₄Cl | 염화암모늄 생성 |
| SO₃ | H₂O | H₂SO₄ | 황산 생성 |
| CaO | H₂O | Ca(OH)₂ | 소석회 생성 |

---

### 7-2. 분류 시너지 (Category Synergy)

분자/화합물은 아래 분류에 속하며, 같은 분류를 **여러 개 합성**하면 시너지 효과 발동.

| 분류 | 예시 분자 | 시너지 효과 |
|------|----------|------------|
| 산 (Acid) | HCl, H₂SO₄, HNO₃, H₂CO₃ | TBD |
| 염기 (Base) | NaOH, KOH, NH₃, Ca(OH)₂ | TBD |
| 염 (Salt) | NaCl, CaSO₄, NH₄Cl | TBD |
| 산화물 (Oxide) | CO₂, SO₂, NO₂, H₂O | TBD |
| 탄화수소 | CH₄, C₂H₂, C₂H₄, C₆H₆ | TBD |
| 알코올 | CH₃OH, C₂H₅OH | TBD |
| 유기산 | HCOOH, CH₃COOH | TBD |

> 보너스 수치는 플레이테스트 후 결정

---

### 7-3. 산-염기 중화 반응 (Neutralization)

**산 분류** 분자 + **염기 분류** 분자가 같은 턴에 존재하면 **중화 반응** 자동 발동.

- 중화 생성물(염 + 물)도 자동 추가 합성
- 4개 분자 모두 점수 계산
- 대형 반응 보너스 (수치 TBD)

**예시**
```
HCl + NaOH  →  NaCl + H₂O
H₂SO₄ + 2NaOH  →  Na₂SO₄ + 2H₂O
```

---

### 7-4. 촉매 시스템 (Catalyst)

특정 분자는 직접 점수 없이 **다른 분자의 점수를 증폭**하는 촉매 역할.

| 촉매 분자 | 촉매 효과 |
|----------|-----------|
| H₂SO₄ (황산) | 같은 턴 유기물 분자 점수 ×1.3 |
| Fe₂O₃ | 같은 턴 산화물 분자 점수 ×1.2 |
| Pt (백금 단독) | 모든 분자 점수 ×1.1 |

> 촉매 분자 자체는 기본 점수 × 0.5만 인정

---

### 7-5. 산화-환원 반응 (Redox)

산화제 역할 분자 + 환원제 역할 분자가 같은 턴에 존재하면 추가 반응 점수.

| 산화제 | 환원제 | 반응 유형 | 보너스 |
|--------|--------|-----------|--------|
| H₂O₂ | — | 분해 반응 | TBD |
| KMnO₄ | 유기물 | 산화 반응 | TBD |

> 구체적인 쌍 목록은 추후 확장

## 8. 턴 구조

```
① 드로우   : 덱에서 6장 드로우
② 합성     : 카드를 그룹화하여 분자/화합물 구성
③ 반응     : 형성된 분자 간 상호작용 자동 계산
④ 득점     : 전체 점수 합산
⑤ 판정     : 커트라인 통과 → 연구 포인트 획득
             커트라인 실패 → 게임 오버
⑥ 쇼핑     : 연구 포인트로 원소 카드 구매 (선택)
⑦ 다음 턴
```

미사용 카드는 버려지며 점수 없음.
