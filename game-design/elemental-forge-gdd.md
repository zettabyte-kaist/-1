# 원소 카드 게임 기획서

**가제**: Elemental Forge (원소 합성사)  
**버전**: 0.4

---

## 1. 게임 개요

원소 주기율표의 원소 카드를 조합하여 실존하는 분자와 화합물을 구성하고,  
매 턴 상승하는 득점 커트라인을 넘어 생존하는 **덱빌딩 카드 게임**.

- **장르**: 덱빌딩 / 생존
- **플레이어**: 1인 (솔로)
- **핵심 키워드**: 원소 조합, 화합물 합성, 반응 연계, 덱 성장

---

## 2. 핵심 메커니즘 요약

1. 덱에서 카드를 드로우하여 **실존하는** 분자/화합물 구성
2. 구성한 분자들 간의 화학 반응으로 추가 점수 획득
3. 매 턴 증가하는 커트라인 통과 시 연구 포인트로 새 원소 카드 획득
4. 더 강력한 화합물을 만들 수 있는 덱으로 성장

> 실존하지 않는 화합물, 원자가 규칙 미충족 조합은 점수 없음.

## 4. 득점 방식

### 기본 점수

분자를 구성하는 원소들의 **원자번호 합산**

```
H₂O  : 1 + 1 + 8        = 10점
CO₂  : 6 + 8 + 8        = 22점
NH₃  : 7 + 1 + 1 + 1   = 10점
NaCl : 11 + 17          = 28점
```

## 6. 덱 구성 방식 (카드 추가)

### 연구 포인트 시스템

매 턴 커트라인 통과 시:
```
연구 포인트 = 획득 점수 - 커트라인
```

### 연구 상점

턴 종료 후 **등급별 원소 카드 3장 랜덤 공개**, 연구 포인트 소비하여 구매.

| 등급 | 카드 비용 | 상점 해금 조건 |
|------|-----------|---------------|
| Grade 2 | 15 ~ 25pt | 턴 1부터 |
| Grade 3 | 35 ~ 55pt | 5턴 이후 |
| Grade 4 | 70 ~ 100pt | 10턴 이후 |
| Grade 5 | 150pt 이상 | 15턴 이후 |

### 주기율표 인접 해금 (선택 규칙)

현재 덱에 있는 원소와 **주기율표상 인접한 원소만** 상점에 등장.

- H, C, O 보유 → N, F, S, P 등이 우선 등장
- 덱이 다양해질수록 상점 선택지도 넓어짐

## 7. 분자/화합물 상호작용 시스템 ⭐

> **게임의 핵심.** 단순 분자 합산이 아닌, 분자들 간 화학적 관계가 점수를 결정한다.  
> 상호작용은 중복 적용 가능하며, 여러 종류를 동시에 발동할수록 콤보 배율이 높아진다.

---

### 7-1. 화학 반응 연계 (Reaction Chain)

같은 턴에 형성된 두 분자가 실제 화학 반응을 일으킬 수 있으면,  
반응 생성물도 **자동 합성**되어 추가 점수 획득.

**규칙**
- 반응 생성물은 카드를 추가 소모하지 않음
- 반응 생성물의 점수는 **기본 점수 × 0.5**
- 반응이 연쇄될 경우 각 단계마다 × 0.5 적용 (단계마다 감쇠)

**예시**

| 반응물 A | 반응물 B | 생성물 | 등급 |
|----------|----------|--------|------|
| CO₂ | H₂O | H₂CO₃ | Grade 1 |
| CO | H₂O | CO₂ | Grade 1 (수성가스) |
| CH₃CHO | H₂O | CH₃COOH | Grade 1 |
| C₂H₄ | H₂O | C₂H₅OH | Grade 1 (수화) |
| HCHO | H₂O | CH₃OH | Grade 1 (환원) |
| NH₃ | HCl | NH₄Cl | Grade 2 |
| SO₃ | H₂O | H₂SO₄ | Grade 2 |
| CaO | H₂O | Ca(OH)₂ | Grade 2 |
| NO | CO₂ | NO₂ | Grade 2 |

---

### 7-2. 분류 시너지 (Category Synergy)

같은 분류 분자를 **같은 턴에 2개 이상** 합성하면 해당 분자 전체에 보너스 적용.

| 분류 | 예시 분자 | 시너지 조건 | 보너스 |
|------|----------|------------|--------|
| 산 (Acid) | HCl, H₂SO₄, HNO₃ | 2개 이상 | 해당 분자 각 +8pt |
| 염기 (Base) | NaOH, NH₃, Ca(OH)₂ | 2개 이상 | 해당 분자 각 +8pt |
| 염 (Salt) | NaCl, CaSO₄, NH₄Cl | 2개 이상 | 해당 분자 각 +10pt |
| 산화물 (Oxide) | CO₂, SO₂, NO₂ | 3개 이상 | 해당 분자 각 +5pt |
| 탄화수소 | CH₄, C₂H₄, C₆H₆ | 2개 이상 | 해당 분자 각 +8pt |
| 알코올 | CH₃OH, C₂H₅OH | 2개 이상 | 해당 분자 각 +10pt |
| 유기산 | HCOOH, CH₃COOH | 2개 이상 | 해당 분자 각 +12pt |
| 에스터 | (7-9 참조) | 2개 이상 | 해당 분자 각 +15pt |

---

### 7-3. 산-염기 중화 반응 (Neutralization)

**산 분류** + **염기 분류** 분자가 같은 턴에 존재하면 **중화 반응** 자동 발동.

- 생성물(염 + 물) 자동 합성 (× 0.6 점수)
- 참여한 산·염기 분자 각각 +15pt 보너스
- 산:염기 = 2:1 또는 1:2 비율로 복수 중화 시 추가 +10pt

**예시**
```
HCl      + NaOH   →  NaCl + H₂O
H₂SO₄   + 2NaOH  →  Na₂SO₄ + 2H₂O
NH₃      + HNO₃   →  NH₄NO₃
```

---

### 7-4. 촉매 시스템 (Catalyst)

특정 분자는 직접 점수 없이 **다른 분자의 점수를 증폭**하는 촉매 역할.  
촉매 분자 자체는 기본 점수 × 0.5만 인정.

| 촉매 분자 | 촉매 효과 |
|----------|-----------|
| H₂SO₄ (황산) | 같은 턴 유기물 분자 점수 ×1.3 |
| Fe₂O₃ | 같은 턴 산화물 분자 점수 ×1.2 |
| MnO₂ | 같은 턴 분해 반응 생성물 점수 ×1.4 |
| Pt 원소 카드 단독 | 모든 분자 점수 ×1.15 |
| Al₂O₃ | 같은 턴 염 분류 점수 ×1.2 |

---

### 7-5. 산화-환원 반응 (Redox)

산화제·환원제 역할 분자가 같은 턴에 함께 존재하면 추가 반응 점수.

| 산화제 | 환원제 | 반응 결과 | 보너스 |
|--------|--------|-----------|--------|
| H₂O₂ | FeCl₂ (Fe²⁺) | 펜턴 반응 | +20pt |
| KMnO₄ | 유기물 (알코올·유기산) | 산화 반응 | +25pt |
| HNO₃ | Cu | CuO + NO₂ 생성 연계 | +20pt |
| H₂O₂ | 단독 | 자기 분해 (MnO₂ 촉매 시) | +10pt |
| Cl₂ (카드) | NaBr 또는 KI 보유 | 할로겐 치환 연계 | +15pt |

---

### 7-6. 침전 반응 (Precipitation)

두 화합물이 반응하여 물에 녹지 않는 **침전물**을 생성.  
침전물은 자동 합성되며 점수 × 0.7 적용.

| 반응물 A | 반응물 B | 침전물 | 색상 |
|---------|---------|--------|------|
| AgNO₃ | HCl 또는 NaCl | AgCl↓ | 흰색 |
| AgNO₃ | KI | AgI↓ | 노란색 |
| BaCl₂ | Na₂SO₄ 또는 H₂SO₄ | BaSO₄↓ | 흰색 |
| BaCl₂ | CaCO₃ (간접) | BaSO₄↓ | 흰색 |
| Pb(NO₃)₂ | KI | PbI₂↓ | 황금색 |
| CuSO₄ | NaOH | Cu(OH)₂↓ | 파란색 |
| FeCl₃ | NaOH | Fe(OH)₃↓ | 적갈색 |

**침전 보너스**: 같은 턴 침전 반응 2회 이상 발생 시 각 침전물 추가 +10pt  
**색상 콤보**: 3가지 이상 다른 색 침전물 생성 시 +30pt (시각적 연출 보너스)

---

### 7-7. 연소 반응 (Combustion)

유기 화합물을 합성한 턴에 CO₂와 H₂O도 함께 합성하면 **연소 반응** 인식.

**완전 연소 조건**: 유기물 + 해당 연소 생성물(CO₂, H₂O) 동시 보유

| 유기물 | 생성물 | 연소 보너스 |
|--------|--------|------------|
| CH₄ | CO₂ + H₂O×2 | 유기물 점수 ×1.5 |
| C₂H₅OH | CO₂×2 + H₂O×3 | 유기물 점수 ×1.5 |
| C₆H₆ | CO₂×6 + H₂O×3 | 유기물 점수 ×2.0 (벤젠 특별) |
| C₆H₁₂O₆ | CO₂×6 + H₂O×6 | 유기물 점수 ×1.8 |

**불완전 연소**: CO + H₂O 구성 시 × 1.2 (산소 부족 시 발동)

> CO₂, H₂O는 각자의 기본 점수도 별도 계산됨

---

### 7-8. 치환 반응 (Displacement)

금속 활성도 순서에 따라 활성이 높은 금속이 화합물 속 낮은 금속을 밀어내는 반응.

**금속 활성 순서 (높음 → 낮음)**
```
K > Ca > Na > Mg > Al > Zn > Fe > Cu > Ag > Au
```

**발동 조건**: 원소 카드 + 해당 원소보다 활성 낮은 금속을 포함한 화합물 동시 보유

| 원소 카드 | 대상 화합물 | 생성물 | 보너스 |
|----------|-----------|--------|--------|
| Fe | CuSO₄ | FeSO₄ + Cu↓ | +15pt |
| Zn | H₂SO₄ | ZnSO₄ + H₂↑ | +15pt |
| Zn | CuSO₄ | ZnSO₄ + Cu↓ | +15pt |
| Na | H₂O | NaOH + H₂↑ | +20pt |
| Mg | HCl | MgCl₂ + H₂↑ | +12pt |

생성물은 자동 합성 (× 0.5 점수 적용)

> 활성도 역전 시 반응 불가 (Au 카드로 NaCl 치환 불가 등)

---

### 7-9. 에스터화 반응 (Esterification)

알코올 + 유기산 → 에스터 + H₂O  
에스터는 새로운 분류로 등록되며, 자동 합성 (× 0.7 점수).

| 알코올 | 유기산 | 에스터 | 기본 점수 |
|--------|--------|--------|----------|
| CH₃OH | CH₃COOH | CH₃COOCH₃ (아세트산메틸) | 32 |
| C₂H₅OH | CH₃COOH | CH₃COOC₂H₅ (아세트산에틸) | 40 |
| C₂H₅OH | HCOOH | HCOOC₂H₅ (폼산에틸) | 32 |
| CH₃OH | HCOOH | HCOOCH₃ (폼산메틸) | 24 |

에스터 분류 시너지: 에스터 2종 이상 → 각 +15pt (7-2 분류 시너지 적용)

---

### 7-10. 열분해 연계 (Thermal Decomposition)

화합물의 분해 생성물을 **같은 턴에 함께 합성**하면 역방향 연계 점수 획득.  
분해 반응을 "예측"하여 재현하는 개념.

| 모화합물 | 분해 생성물 | 보너스 |
|---------|-----------|--------|
| CaCO₃ | CaO + CO₂ | 모화합물 점수 × 0.6 추가 |
| 2H₂O₂ | H₂O + O₂ | 모화합물 점수 × 0.6 추가 |
| 2HgO | Hg + O₂ | 모화합물 점수 × 0.7 추가 |
| NH₄Cl | NH₃ + HCl | 모화합물 점수 × 0.6 추가 |
| 2NaHCO₃ | Na₂CO₃ + H₂O + CO₂ | 모화합물 점수 × 0.8 추가 |

> MnO₂ 촉매가 같은 턴에 있으면 보너스 배율 +0.1 추가

---

### 7-11. 동족체 시너지 (Homologous Series)

같은 유기 화합물 계열(동족체)을 **같은 턴 2개 이상** 완성하면 시너지.

| 계열 | 일반식 | 예시 | 조건 | 보너스 |
|------|--------|------|------|--------|
| 알케인 | CₙH₂ₙ₊₂ | CH₄, C₂H₆, C₃H₈ | 2종 | 각 +10pt |
| 알켄 | CₙH₂ₙ | C₂H₄, C₃H₆ | 2종 | 각 +10pt |
| 알코올 | CₙH₂ₙ₊₁OH | CH₃OH, C₂H₅OH | 2종 | 각 +12pt |
| 유기산 | CₙH₂ₙO₂ | HCOOH, CH₃COOH | 2종 | 각 +12pt |
| 알데하이드 | CₙH₂ₙO | HCHO, CH₃CHO | 2종 | 각 +10pt |

계열 내 3종 이상 완성 시 보너스 2배 적용

> ✅ **구현 완료** (v0.4): Grade 1 원소(H/C/O)만으로 알케인·알코올·유기산·알데하이드 시너지 발동 가능

### 7-12. 산업 합성 루트 (Industrial Synthesis Route)

실존하는 산업 공정의 반응 경로를 **단일 턴 내에 재현**하면 대형 보너스.  
각 공정에 필요한 중간 생성물을 모두 합성해야 인정.

| 공정명 | 필요 화합물 | 보너스 |
|--------|-----------|--------|
| **하버-보슈법** (암모니아) | N₂(원소 카드) + H₂ → NH₃ | +50pt |
| **접촉법** (황산) | S→SO₂→SO₃→H₂SO₄ 순서 보유 | +60pt |
| **오스트발트법** (질산) | NH₃→NO→NO₂→HNO₃ 순서 보유 | +60pt |
| **솔베이법** (탄산나트륨) | NaCl+CO₂+NH₃→NaHCO₃→Na₂CO₃ | +70pt |
| **석회 제조** | CaCO₃→CaO→Ca(OH)₂ 순서 보유 | +40pt |

> 같은 턴에 경로의 모든 화합물이 존재해야 인정

### 7-13. 콤보 배율 (Combo Multiplier)

한 턴에 여러 종류의 상호작용을 **동시에** 발동하면 최종 턴 득점에 누적 배율 적용.

| 발동 상호작용 종류 수 | 배율 |
|-----------------|------|
| 1종 | ×1.0 (기본) |
| 2종 | ×1.2 |
| 3종 | ×1.5 |
| 4종 | ×1.8 |
| 5종 이상 | ×2.5 |

**카운트 대상 상호작용 목록**
반응 연계 / 분류 시너지 / 중화 반응 / 촉매 / 산화환원 / 침전 / 연소 / 치환 / 에스터화 / 열분해 / 동족체 / 합성 루트

> 콤보 배율은 해당 턴 총 기본 점수 합산에 적용 (개별 분자가 아닌 턴 전체)

## 8. 턴 구조

```
① 드로우   : 덱에서 8장 드로우
② 합성     : 카드를 그룹화하여 분자/화합물 구성
③ 반응     : 형성된 분자 간 상호작용 자동 계산
④ 득점     : 전체 점수 합산 + 콤보 배율 적용
⑤ 누적     : 구간 누적 점수에 이번 턴 점수 추가
             (5턴마다 구간 심사 — 아래 참고)
⑥ 쇼핑     : 5턴 구간 통과 시에만 상점 오픈 (연구 포인트 소비)
⑦ 다음 턴
```

미사용 카드는 버려지며 점수 없음.

### 5턴 구간 심사

- 5턴을 한 **구간(Period)**으로 묶어 누적 점수를 합산
- 구간 내 각 턴에는 게임 오버 없음 → 한 턴이 망해도 다음 턴으로 만회 가능
- 구간 종료 시 `누적 점수 ≥ 구간 목표`이면 통과, 아니면 게임 오버
- 통과 시 `(누적 점수 - 구간 목표) = 연구 포인트` 지급 + 상점 오픈

---

## 9. 구간 목표 (5턴 누적)

| 구간 | 턴 범위 | 누적 목표 | 평균 필요 (턴당) |
|------|--------|----------|---------------|
| 1기 | 1~5턴   | 100pt  | ~20pt/턴 |
| 2기 | 6~10턴  | 280pt  | ~56pt/턴 |
| 3기 | 11~15턴 | 560pt  | ~112pt/턴 |
| 4기 | 16~20턴 | 1100pt | ~220pt/턴 |
| 5기 | 21~25턴 | 2000pt | ~400pt/턴 |
| 6기 이후 | 이후 | 전 구간 × 2.0 | — |

> Grade 1(H/C/O)만으로 1기는 충분히 통과 가능 (상호작용 포함 시 턴당 40~80pt 기대)
